# adc-adder16

De entrada, se toman dos números de 16 bits en A y B, y de ser necesario, un valor de acarreo de entrada de 1 bit.  De no ser necesario este valor, enviar la constante 0.  Se devuelve una salida de 16 bits correspondiente a la suma entre A y B, más un bit indicando el carry de salida, que será 1 si la suma excedió los 16 bits de tamaño.
